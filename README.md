# [LA-6] 파일에 저장하기

첨부 과제 PDF와 기존 LA-5 FRAME 코드를 바탕으로 만든 LA-6 완성본입니다.
AI: ChatGPT. 프롬프트: 기존 영화 상영표를 PHP 서버 파일 저장 방식으로 변경하고 LA-6의 검사·포스터·안전한 출력 조건을 구현해 주세요.

## 실행

PHP 8.1 이상과 fileinfo 확장이 필요합니다. 웹 서버 프로세스가 프로젝트 폴더와 uploads에 쓸 수 있어야 합니다.

```bash
cd LA6
php -S localhost:8000
```

브라우저에서 로컬 서버의 index.php를 엽니다. HTML 파일을 직접 여는 방식으로는 PHP가 실행되지 않습니다.
`php` 명령을 찾지 못하면 PHP 실행 파일을 PATH에 추가하거나 실행 파일의 전체 경로를 사용하세요.

## 파일 구성과 변경 이유

- index.php: 기존 index.html을 PHP 템플릿으로 바꿔 페이지를 열 때 서버 파일을 읽고, 모달과 달력을 표시합니다.
- add.php: 모든 검사 후 파일에 추가하고 Session에 결과를 맡겨 303으로 돌아옵니다. 새로고침은 재등록하지 않습니다.
- validation.php: 기존 LA-5 조건, 지난 날짜, 같은 날짜·시간, 10분 정리 시간, 실제 이미지·2MiB 제한을 검사합니다.
- storage.php: 손상 자료를 덮어쓰지 않습니다. 잠금 안에서 최신 목록을 검사하고 임시 파일로 전체 배열을 교체합니다.
- js/app.js: 파일에서 받은 배열만 표시합니다. textContent로 제목을 안전하게 표시합니다.
- js/validation.js: 보내기 전 모든 클라이언트 오류를 모읍니다. form.submit()으로 우회해도 PHP가 다시 검사합니다.
- style.css: 기존 FRAME의 어두운 배경과 연두색 카드, 밝은 테마, 반응형 화면을 유지합니다.
- screenings.json / uploads/: 실제 등록한 예시 상영 2개와 검증용 포스터 1개를 포함합니다.
- docs/화면캡처.docx: 주소창을 포함한 필수 ⓐ~ⓕ 실제 실행 캡처(ⓑ는 전·후 2개)를 포함합니다.

기존 index.html과 js/result.js는 이 버전에서 사용하지 않습니다. localStorage 저장, 예시 직접 추가, 수정·삭제·복구 기능을 제거했습니다.
포스터 선택은 선택 사항이며 등록 중 미리보기는 제공하지 않습니다. 정상 이미지는 서버가 생성한 ID와 내용에 맞는 확장자로 uploads에 저장합니다.
오류가 발생하면 입력을 유지하며, 보안상 브라우저가 파일 선택을 복원할 수 없으므로 포스터는 다시 선택합니다.
제목의 script 문자열은 원문 그대로 저장하고 PHP escaping, JSON_HEX 옵션, DOM textContent로 안전하게 표시합니다.
새 날짜는 Asia/Seoul 기준으로 검사하며, 과거 상영은 달력에 계속 표시됩니다.

## 검증 및 제출

PHP 8.4.26 실제 HTTP 통합 검사 18개, 실제 Chromium 브라우저 검사 11개가 통과했습니다.
정상 저장, 브라우저 종료 후 유지, 중복·지난 날짜·다중 오류·가짜 이미지·용량 초과 차단, 손상 파일 보존, 동시 중복 요청, 포스터 표시, XSS, 검색·목록·반응형 화면을 확인했습니다.
최종 CSS 화면과 모바일 모달도 다시 확인했습니다. PHP Warning과 브라우저 Console 오류는 발생하지 않았습니다.

학번과 이름은 제공되지 않아 문서에 입력란을 남겼습니다. 문서에 본인 정보를 입력한 뒤 전체 폴더를 `[LA-6] 학번_이름.zip`으로 압축해 제출하세요.
첨부 화면 캡처.hwpx는 LA-5 화면이라 새 LA-6 캡처 문서로 대체했습니다.
